# Drop 临时取件站

用四位取件码，在设备之间临时传递文件或文字。无需注册，不用自备服务器，部署到 **EdgeOne Makers** 即可使用。

**[在线 Demo](https://drop.nmdft.cn)** · [部署指南](docs/DEPLOY.md) · [MIT License](LICENSE)

## 怎么用

1. 打开站点，粘贴文字或选择一个文件。
2. 选择保留时间，点击「生成取件码」。
3. 在另一台设备输入四位码，或直接打开分享链接，即可取件。

有效期内可重复领取；发送者可以提前撤销。

## 特性与规格

- 文件最大 **300MB**，文字最大 **1MB**，支持手机与电脑浏览器。
- 已存容量达到 **700MB** 时，新文件上限降为 **10MB**；剩余容量不足时仍会拒绝上传。
- 默认保留 **1 小时**，可选 3 小时、1 天、3 天。到期立即停止领取，每天北京时间 **03:23** 清理已过期内容，不再统一保留三天。
- 使用 Makers Cloud Functions 和 Blob，无需自备服务器或另建数据库。
- 分块传输、发送者撤销、基础限流与浅色／深色主题。

> 四位码不是密码，本项目没有端到端加密。请勿上传敏感内容；Demo 仅供体验。

## 部署自己的 Drop

1. **Fork 本仓库**，在 EdgeOne Makers 中导入你自己的 GitHub 仓库。
2. 安装命令 `npm ci`，构建命令 `npm run build`，输出目录 `dist`。
3. 首次填写两个自己生成的随机密钥，随后部署即可；Makers 会自动配置每日清理。具体步骤见 **[部署指南](docs/DEPLOY.md)**。

Blob 运行凭据由平台注入，无需手动申请数据库或填写存储账号。无需在 GitHub 配置定时任务。两个密钥用于签名和保护清理接口，不能安全地换成公开默认值；只需首次配置，不是每次部署都要修改。
